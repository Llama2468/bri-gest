Method

Each tool queries the NCBI E-utilities API directly from the browser and displays abstracts verbatim. Nothing is summarised, ranked or rewritten by a language model. What you read is what PubMed returned.

Search strategies derive from published guideline strategies and are versioned alongside the code. The full query for any lane is visible in each tool's audit panel and reproducible in PubMed.

Impact factors are approximate 2024 JCR values, shown for triage only. Results cache for 6 hours; refresh to re-query.
